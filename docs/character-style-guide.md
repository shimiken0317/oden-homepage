# おでんちゃん キャラクタースタイルガイド

この文書は完成した設定集ではなく、彼女の原画を守りながらイラスト制作を依頼・確認するためのテンプレートです。迷ったときはこの文書より原画を優先し、分からないことは推測せず彼女へ確認します。

## 1. キャラクターの由来

「おでんちゃん」は、彼女が彼氏をイメージして描いた大切なオリジナルキャラクターです。おでんをモチーフに、筋トレ・投資・プログラミング・日記など、二人の日常や成長を少し不器用ながら一生懸命案内します。

単なる装飾や、一般的な「かわいいマスコット」の一種として扱いません。二人の関係と原画にある個性が、サイトブランドの中心です。

## 2. 原画最優先の原則

1. 制作対象として二人が指定した原画を、形・構図・表情・具の配置・線・色の最優先資料とします。
2. このガイドと原画が食い違う場合、そのイラストでは原画を優先します。
3. 見えない部分や曖昧な部分を、既製のキャラクター表現で補いません。
4. 判断できない点は「確認事項」として残し、彼女の回答前に確定しません。
5. 原画ファイル自体は非公開領域に置き、公開画像として流用しません。

## 3. 絶対に変えてはいけない要素

- 彼女が彼氏をイメージして描いたキャラクターであること。
- おでんの具を重ねた、手描き感のある素朴な姿。
- 親しみやすく、少し不器用でも一生懸命な雰囲気。
- 原画にある顔、輪郭、具の形、身体の比率を別キャラクター風に整えないこと。
- 写実的な人間、動物、3Dマスコット、量産型の企業キャラクターへ置き換えないこと。
- 原画にないロゴ、文字、記号、衣装、身体部位を勝手に加えないこと。

## 4. 通常形のおでんの具の順番

現在の通常形の基準は、上から次の順番です。

1. こんにゃく：帽子のように上に載る。
2. たまご：顔になる中央の具。
3. ちくわ：身体になる下の具。

向き、重なり方、形、具の大きさは原画を参照します。すべての場面を同じ幾何学形状へ統一しません。

## 5. 原画が通常形と違う場合

特定の原画で具の順番、形、姿勢、身体比率が通常形と異なる場合は、「誤り」として自動修正しません。その違いが場面の表現なのか、ラフ段階の省略なのかを彼女へ確認します。

- 意図が確認できた場合：その原画固有の表現として維持する。
- 意図が不明な場合：生成依頼書の確認事項へ記載し、制作を止める。
- 通常形へ戻す指示がある場合：どこを戻すかを依頼書に明記する。

## 6. 線の特徴

- 鉛筆やペンで描いたような、わずかな揺れと手の動きが感じられる線。
- 輪郭を機械的に均一化せず、原画の素朴さを残す。
- 過度に太い漫画線、完全なベクター線、光沢の強い3D輪郭へ変えない。
- 「きれいにする」ことを目的に、原画の不揃いさや表情を消さない。

## 7. 色の方針

- 原画の柔らかく控えめな色合いを基準にする。
- たまご・ちくわの温かい黄〜練り物色、こんにゃくの落ち着いた灰色を尊重する。
- 彩度、コントラスト、陰影を過度に強くしない。
- ネオンカラー、金属光沢、強いグラデーション、写実的な質感を勝手に加えない。
- サイトの背景色上で輪郭と表情が読めることを確認する。

## 8. 表情

- 原画に描かれた表情を優先し、喜怒哀楽を誇張しすぎない。
- 一生懸命さ、困り顔、少し抜けた感じ、穏やかな笑顔を自然に扱う。
- 目・口・眉・頬・汗の有無や位置を、依頼内容から勝手に変更しない。
- 怖さ、攻撃性、皮肉、過度な幼児化、性的表現を加えない。

## 9. ポーズ

- 指定原画の重心、傾き、手足、道具との関係を維持する。
- 筋トレでは「強く見せる」より、一生懸命取り組む姿を優先する。
- 可動範囲や手足の構造を推測で増やさない。
- 複雑なポーズは、必要な原画または彼女の確認が揃うまで生成しない。

## 10. 小物

- ダンベル、バーベル、本、PCなど、依頼で指定された小物だけを使う。
- 小物が主役にならず、おでんちゃんの形や表情を隠しすぎない。
- ブランドロゴ、商品名、画面上の文字は必要性と権利を確認する。
- 原画にない衣装やアクセサリーは、彼女の明示承認なしに追加しない。

## 11. 禁止事項

- 原画を学習素材として無断公開・共有すること。
- 一般的なマスコット風、アニメ風、3D映画風、企業キャラクター風への再設計。
- 具の入れ替え、別の食べ物・動物・人間への置換。
- 人数、構図、表情、動作、道具を依頼なく変更すること。
- 原画にない文字、吹き出し、透かし、署名、ロゴの追加。
- 過剰なデフォルメ、赤ちゃん化、筋肉の誇張、写実化。
- 彼女の確認前に「公式」「完成」「承認済み」と扱うこと。
- 未承認画像を `public/` や `content/illustrations/*.yaml` へ登録すること。

## 12. 背景

- Web記事の挿絵用は、原則として背景透過。
- 接地影や小さな汗・きらめきなども、原画または依頼で指定されたものだけを残す。
- 背景が必要な場面は、色・範囲・用途を依頼書で明記して別途承認する。
- 不要な白背景、風景、模様、装飾枠を自動追加しない。

## 13. 出力形式

承認前：

- 背景透過PNGを基本とする。
- sRGB。
- Web掲載前の確認に十分な解像度。
- 原画名や個人情報を画像メタデータ・ファイル名へ含めない。
- `.private/illustration-review/` だけに保存する。

承認後：

- Web用はWebPを第一候補とし、透明表現や画質上必要ならPNGを使用する。
- ファイル名は台帳の `id` と合わせた英小文字・数字・ハイフンにする。
- 公開先は `public/characters/oden-chan/illustrations/` に限定する。
