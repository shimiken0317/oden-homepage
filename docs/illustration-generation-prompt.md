# おでんちゃん イラスト生成依頼テンプレート

このテンプレートは、ChatGPTなどの画像生成機能へ人間が依頼するときに使います。画像生成結果は候補であり、二人が承認するまでは公開用素材ではありません。

原画をサービスへアップロードできるか、利用規約・保存設定・学習利用設定を事前に二人で確認してください。確認できないサービスへ原画を渡さないでください。

## 依頼テンプレート

```text
添付した画像は、彼女が彼氏をイメージして描いたオリジナルキャラクター
「おでんちゃん」の非公開原画です。

この原画と、別途添付する character-style-guide.md を参照して、
Web記事向けのイラスト候補を制作してください。

最優先事項：
- 原画を最優先し、一般的なマスコットとして再解釈しない
- 原画の手描き感、素朴さ、柔らかい色、一生懸命な雰囲気を残す
- 構図、人数、表情、動作、具の順番、小物を勝手に変更しない
- 見えない部分や曖昧な部分を推測で補わない
- 曖昧な点があれば、生成前に「確認事項」として箇条書きで質問する
- 不要な文字、吹き出し、ロゴ、署名、透かしを画像へ追加しない

今回の指定：
- 依頼ID：{{REQUEST_ID}}
- タイトル：{{TITLE}}
- 使用する原画：{{人間が添付した原画の説明}}
- 人数：{{例：おでんちゃん1人}}
- 構図：{{原画どおり。必要なら具体的に記載}}
- 表情：{{原画どおり。必要なら具体的に記載}}
- 動作：{{原画どおり。必要なら具体的に記載}}
- 小物：{{なし／原画にあるものだけ／具体的な指定}}
- 記事テーマ：{{筋トレ、投資、プログラミング、日記など}}
- 想定配置：{{記事冒頭、見出し後、空状態など}}
- 画像比率：{{TODO：用途に合わせて人間が指定}}

出力仕様：
- 背景透過
- PNG
- sRGB
- Web記事で縮小表示しても表情が読めること
- キャラクターや小物を画像端で切らない
- 原画にない背景や装飾を加えない

生成前に行うこと：
1. 理解した構図、人数、表情、動作、小物を短く復唱する
2. 原画から判断できない箇所を確認事項として列挙する
3. 確認事項がある場合は、回答を待ってから生成する

重要：
この生成結果はまだ公開用素材ではありません。
「承認済み」「公式素材」「公開可能」と表示せず、
人間による確認待ちの候補として扱ってください。
```

## 生成後

1. ダウンロードした候補を `.private/illustration-review/` に保存します。
2. [character-style-guide.md](character-style-guide.md) の承認チェックリストで二人が確認します。
3. 修正が必要なら、元の依頼IDを維持して再依頼します。
4. 両者が承認するまでは `public/` へ移動せず、Gitにも追加しません。
